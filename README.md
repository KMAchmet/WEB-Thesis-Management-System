# Thesis Support System

Application skeleton built with **PHP, MySQL, AJAX & Chart.js**.

---

## 📁 Project Structure

- `index.html`, `login.php`, `logout.php`: Home page & authentication
- `announcements.php`: Public feed (`JSON`/`XML`)
- `student/`, `professor/`, `secretary/`: Role-specific dashboards
- `includes/`: Database connection (`db.php`) & auth helpers
- `db/`: SQL scripts & seed data (`seed_users.php`, default password: `password123`)
